Description

Declarative in-server state management for RustFS object-storage servers via native modules speaking the S3 and admin APIs directly: buckets, versioning, lifecycle, quota, IAM policies/users/groups/service accounts, policy attachments, and credential liveness verification, with check mode as drift detection.

  • David Igou <igou.david@gmail.com>
