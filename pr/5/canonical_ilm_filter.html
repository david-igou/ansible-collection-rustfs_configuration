david_igou.rustfs.canonical_ilm filter – Canonicalize a RustFS ILM rule list for comparison

Note

This filter plugin is part of the david_igou.rustfs collection (version 2.0.0).

It is not included in ansible-core. To check whether it is installed, run ansible-galaxy collection list.

To install it, use: ansible-galaxy collection install david_igou.rustfs.

To use it in a playbook, specify: david_igou.rustfs.canonical_ilm.

New in david_igou.rustfs 2.0.0

  • Synopsis

  • Input

  • Examples

  • Return Value

Synopsis

  • Strips server-generated rule ids (lowercase id — the only casing rc 0.1.x emits) and orders rules deterministically.

  • rc ilm rule import requires an id on every rule while the server may regenerate them; stripping ids on both sides of a comparison prevents false drift either way.

  • Also drops empty scoping (an empty top-level prefix or an empty filter) so a whole-bucket rule written with an explicit empty prefix/filter still matches the server’s export, which omits it — a NON-empty filter is left as-is (the server honours only a top-level prefix).

Input

This describes the input of the filter, the value before | david_igou.rustfs.canonical_ilm.

Parameter

Comments

Input

list / elements=dictionary / required

ILM rule list, as exported by rc ilm rule export.

Examples

- name: Compare live lifecycle rules against the spec
  ansible.builtin.set_fact:
    matches: >-
      {{ (live_rules | david_igou.rustfs.canonical_ilm)
         == (spec_rules | david_igou.rustfs.canonical_ilm) }}

Return Value

Key

Description

Return value

list / elements=string

The canonicalized rule list.

Returned: success
